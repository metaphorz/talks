Coding with Claude
2H · Code · the workflow

    

      
1
Describe
Say what it should do
Who it is for, what it shows, what happens when you click. Name the language if you care: “a single HTML page”.

      
2
Preview
See it run
On claude.ai, small programs appear as an artifact beside the chat. You can use them right away.

      
3
Iterate
One change at a time
“Make the ball bigger.” “Add a slider.” Small requests are easier to check.

      
4
Understand
Ask it to explain
“Explain this line.” “What would break if…?” Reading the code is the attention muscle again.

      
5
Fix
Paste the error
If it breaks, copy the error message or describe what you see. Let it find the cause.

      
6
Go bigger
Claude Code
For whole projects, Claude works in your files and terminal. Both talks were built that way.

    

    
You still decide what to build, and whether it is right.

Guidelines for Media
Using AI honestly

    

      
1 · Transparency
Label what AI made
Say which parts were generated — the music, the image, the voice — and with which tool. Viewers can't always tell anymore.

      
2 · Copyright
Respect others' work
Painting styles are free to learn from; particular works, voices and likenesses are not. Read each tool's terms before you publish.

      
3 · Credit
Credit people and tools
Name yourself as the maker, and the tools that helped. Credit the people whose work or place you portray.
